# NCCL Release 2.8.4

{#release-notes-section_n2q_kp4_phb}
This is the NCCL 2.8.4 release notes. For previous NCCL release notes, refer to the [NCCL Archives](https://docs.nvidia.com/deeplearning/sdk/nccl-archived/index.html).

## Compatibility

NCCL 2.8.4 has been tested with the following:

-   Deep learning framework containers. Refer to the [Support Matrix](https://docs.nvidia.com/deeplearning/frameworks/support-matrix/index.html) for the supported container version.
-   This NCCL release supports [CUDA 10.1](https://docs.nvidia.com/cuda/archive/10.1/index.html), [CUDA 10.2](https://docs.nvidia.com/cuda/archive/10.2/index.html), [CUDA 11.0](https://docs.nvidia.com/cuda/archive/11.0_GA/), [CUDA 11.1](https://docs.nvidia.com/cuda/archive/11.1.0/), and [CUDA 11.2](https://docs.nvidia.com/cuda/archive/11.2.0/).

## Key Features and Enhancements

This NCCL release includes the following key features and enhancements.

-   Added support for Zhaoxin CPUs

## Known Issues

Send/receive operations have a number of limitations:

-   Using send/receive operations in combination to launch work on multiple GPUs from a single process can fail or hang if the GPUs process different amounts of data. Setting `NCCL_LAUNCH_MODE=PARALLEL` can work around the issue, but can also cause other problems. For more information, see the [NCCL User Guide](https://docs.nvidia.com/deeplearning/nccl/archives/nccl_284/user-guide/docs/index.html) section **Troubleshooting** &gt; **Known Issues** &gt; [Concurrency Between NCCL and CUDA calls](https://docs.nvidia.com/deeplearning/nccl/archives/nccl_284/user-guide/docs/troubleshooting.html#concurrency-between-nccl-and-cuda-calls-nccl-up-to-2-0-5-or-cuda-8).

## Fixed Issues

The following issues have been resolved in NCCL 2.8.4:
