# NCCL Release 2.9.8

{#release-notes-section_n2q_kp4_phb}
This is the NCCL 2.9.8 release notes. For previous NCCL release notes, refer to the [NCCL Archives](https://docs.nvidia.com/deeplearning/sdk/nccl-archived/index.html).

## Compatibility

NCCL 2.9.8 has been tested with the following:

-   Deep learning framework containers. Refer to the [Support Matrix](https://docs.nvidia.com/deeplearning/frameworks/support-matrix/index.html) for the supported container version.
-   This NCCL release supports [CUDA 10.1](https://docs.nvidia.com/cuda/archive/10.1/index.html), [CUDA 10.2](https://docs.nvidia.com/cuda/archive/10.2/index.html), [CUDA 11.0](https://docs.nvidia.com/cuda/archive/11.0_GA/), and [CUDA 11.3](https://docs.nvidia.com/cuda/archive/11.3.0/).

## Key Features and Enhancements

This NCCL release includes the following key features and enhancements.

-   Added support for `nvidia-peermem` module.

## Fixed Issues

The following issues have been resolved in NCCL 2.9.8:

-   Fixed error when injecting a topology file without vendor/device information.
-   Fixed crash in bootstrap error case.
-   Fixed memory leaks.
-   Fixed `collnet` clean-up issue.
