# NIIN Test Suite — Instructions for Running on Any System

## Prerequisites

1. **NCCL built** for the target GPU arch:
   ```bash
   cd /path/to/nccl
   make src.build CUDA_HOME=/path/to/cuda \
       NVCC_GENCODE="-gencode=arch=compute_XX,code=sm_XX" -j$(nproc)
   ```
   Replace `XX` with: `90` (H100/H200), `89` (L40S/L4/RTX4090), `80` (A100), `70` (V100).

2. **MPI installed** (OpenMPI or MPICH). The script needs `mpirun`.

3. **NVSHMEM source** checked out (for functional compat tests). If not available, use `--skip-func` to run only perftests.

4. **At least 2 GPUs** visible. For P2P tests, use GPUs on the same NUMA node. For IB tests, need an active IB HCA.

## Quick Start

```bash
cd /path/to/nccl

# Run everything (P2P + IB, functional + perf):
NCCL_HOME=/path/to/nccl \
NVSHMEM_HOME=/path/to/nvshmem \
MPI_HOME=/path/to/mpi \
bash contrib/niin/test/run_all.sh --all

# Results appear in contrib/niin/test/results/
# This directory is generated by the test runner and ignored by git.
```

## Options

| Flag | Description |
|---|---|
| `--p2p` | Run P2P/LSA mode only (peer pointer path) |
| `--ib` | Run IB loopback mode only (GIN network path) |
| `--all` | Run both P2P and IB (default) |
| `--build-only` | Compile tests but don't run |
| `--skip-perf` | Skip performance tests |
| `--skip-func` | Skip functional tests |

## Environment Variables

| Variable | Default | Description |
|---|---|---|
| `NCCL_HOME` | Auto-detect from script location | Path to NCCL repo root (must have `build/lib/libnccl.so` and `build/include/nccl.h`) |
| `NVSHMEM_HOME` | `/storage/benjaming/repo/nvshmem` | Path to NVSHMEM source (needs `test/device/` directory) |
| `MPI_HOME` | `/cm/shared/apps/openmpi4/gcc/4.1.8` | Path to MPI install (needs `bin/mpirun`, `include/`, `lib/`) |
| `ARCH` | Auto-detected from GPU name | CUDA arch (`sm_90`, `sm_89`, `sm_80`) |
| `HCA` | Auto-detected (first active mlx5) | IB HCA for loopback mode |
| `GPU_PAIR` | `0,1` | Comma-separated GPU IDs to use |
| `NP` | `2` | Number of MPI processes |
| `RESULTS_DIR` | `contrib/niin/test/results/` | Generated output directory for CSV files; ignored by git |

## Choosing the Right GPU Pair

**For P2P tests**: Use GPUs on the **same NUMA node** for best results. Check with:
```bash
nvidia-smi topo -m
```
Look for `NODE` or `NV12`/`NV18` connections (not `SYS`).

**For NVLink bandwidth**: Use GPUs connected via NVLink (`NV12`/`NV18` in topo matrix):
```bash
# Example: H100 NVL pair at GPU 0,3
GPU_PAIR=0,3 bash contrib/niin/test/run_all.sh --p2p
```

**For IB loopback**: Any GPU pair works. The script disables P2P and routes through the HCA. Cross-NUMA is fine:
```bash
GPU_PAIR=0,2 bash contrib/niin/test/run_all.sh --ib
```

## Output Files

The test runner creates `RESULTS_DIR` if it does not already exist. Result CSVs
are local artifacts for debugging and comparison, not source files to commit.

| File | Contents |
|---|---|
| `system_info.csv` | GPU, driver, CUDA version, topology |
| `build_results.csv` | Build status for each test (OK/FAIL) |
| `func_p2p.csv` | Functional test results in P2P mode |
| `func_ib.csv` | Functional test results in IB mode |
| `perf_p2p.csv` | Performance numbers in P2P mode |
| `perf_ib.csv` | Performance numbers in IB mode |
| `functional_results.csv` | Merged functional results (all modes) |
| `performance_results.csv` | Merged performance results (all modes) |

### CSV Formats

**Functional**: `test,mode,status,detail`
- status: `PASS`, `FAIL`, `XFAIL` (expected failure), `XPASS` (expected fail but passed)

**Performance**: `test,mode,scope,size_bytes,value,unit`
- test: `put_latency`, `put_bw`, `get_latency`, `put_signal_latency`
- scope: `Thread`, `Warp`, `Block`
- unit: `us` (latency) or `GB/s` (bandwidth)

## Platform-Specific Notes

### H100/H200 (sm_90)
- NVLink pairs: check `nvidia-smi topo -m` for `NV12`/`NV18` connections
- NVLS multicast: `nvshmemx_mc_ptr` may return non-null on NVSwitch systems
- Expected P2P put BW: 200-400 GB/s on NVLink, ~26 GB/s on PCIe Gen5

### L40S (sm_89)
- No NVLink — all P2P is via PCIe
- Expected P2P put BW: ~20 GB/s (PCIe Gen4)
- Expected IB put BW: ~12.4 GB/s (100Gb/s HCA)

### A100 (sm_80)
- NVLink between GPUs on same NVSwitch
- Expected P2P put BW: 300+ GB/s on NVLink

## Troubleshooting

**Tests hang**: Kill stale GPU processes:
```bash
nvidia-smi --query-compute-apps=pid --format=csv,noheader | xargs -r kill -9
```

**"ncclCommInitRank failed"**: Check that MPI is working:
```bash
mpirun -np 2 --allow-run-as-root hostname
```

**IB tests hang**: Verify HCA is active:
```bash
ibstat | grep -E "^CA|State:"
```

**Build fails**: Ensure NCCL is built for the correct arch:
```bash
ls build/lib/libnccl.so.2.* && nm build/lib/libnccl.so.2.* | grep ncclCommInitRank | head -1
```

**"NIIN: symmetric heap exhausted"**: Increase heap size:
```bash
NVSHMEM_SYMMETRIC_SIZE=2G bash contrib/niin/test/run_all.sh --p2p --skip-func
```

## Comparing with NVSHMEM

To get NVSHMEM baseline numbers for comparison, run the NVSHMEM perftests:
```bash
NVSHMEM_DIR=/path/to/nvshmem/build
LD_LIBRARY_PATH=$NVSHMEM_DIR/src/lib:$LD_LIBRARY_PATH \
NVSHMEMTEST_USE_MPI_LAUNCHER=1 \
CUDA_VISIBLE_DEVICES=0,1 \
mpirun -np 2 $NVSHMEM_DIR/perftest/device/pt-to-pt/shmem_put_bw \
    -b 1024 -e 67108864 -n 16 -t 256
```
