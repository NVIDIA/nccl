# NCCL Release 2.5.6

{#release-notes-section_n2q_kp4_phb}
This is the NCCL 2.5.6 release notes. For previous NCCL release notes, refer to the [NCCL Archives](https://docs.nvidia.com/deeplearning/sdk/nccl-archived/index.html).

## Key Features and Enhancements

This NCCL release includes the following key features and enhancements.

-   Added new protocol to improve performance on small operations.
-   Improved topology detection and tree/ring creation \([\#179](https://github.com/NVIDIA/nccl/issues/179), [\#262](https://github.com/NVIDIA/nccl/issues/262)\).
-   Improved multi-node tree performance by sending/receiving from different GPUs.
-   Added model-based tuning to switch between the different algorithms and protocols.
-   Reworked P2P/SHM detection in containers \([\#155](https://github.com/NVIDIA/nccl/issues/155), [\#248](https://github.com/NVIDIA/nccl/pull/248)\).
-   Added detection for duplicate CUDA devices and return an error \([\#231](https://github.com/NVIDIA/nccl/issues/231)\).
-   Added tuning for Google Cloud’s gVNIC platform.

## Compatibility

NCCL 2.5.6 has been tested with the following:

-   Deep learning framework containers. Refer to the [Support Matrix](https://docs.nvidia.com/deeplearning/frameworks/support-matrix/index.html) for the supported container version.
-   This NCCL release supports [CUDA 9.0](https://docs.nvidia.com/cuda/archive/9.0/index.html), [CUDA 10.0](https://docs.nvidia.com/cuda/archive/10.0/index.html), [CUDA 10.1](https://docs.nvidia.com/cuda/archive/10.1/index.html), and [CUDA 10.2](https://docs.nvidia.com/cuda/archive/10.2/index.html).

## Fixed Issues

The following issues have been resolved in NCCL 2.5.6:

-   Sporadic NCCL error "ring 0 does not loop back to start” \([\#179](https://github.com/NVIDIA/nccl/issues/179)\).
-   NCCL doesn't form proper rings on GCP V100s \([\#262](https://github.com/NVIDIA/nccl/issues/262)\).
