# C: Device API AllGather with CFT multimem counted

Build from this directory:

```shell
make [MPI=1] [MPI_HOME=<path-to-mpi>] [NCCL_HOME=<path-to-nccl>] [CUDA_HOME=<path-to-cuda>]
```

Run:

```shell
./allgather_cft_multimem_counted
```
