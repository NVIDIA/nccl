# NCCL 2.32.3 Performance - Peak BusBW

<pre>
NCCL Version : 2.32.3
CUDA Version : per platform (see Versions)
Metric       : Bus BW in GB/s
Aggregation  : 3-run average, out-of-place only
</pre>

See the [performance data guidance](README.md) for how to interpret these
reference results.

## Test Commands

Tests can be launched as follows:

```bash
# Legacy (MessageSize=8GB)
${MPIRUN_COMMAND} all_reduce_perf -t1 -g1 -f2 -b8G -e8G -w5 -n20 -dfloat -R0 -G10
${MPIRUN_COMMAND} all_gather_perf -t1 -g1 -f2 -b8G -e8G -w5 -n20 -dfloat -R0 -G10
${MPIRUN_COMMAND} reduce_scatter_perf -t1 -g1 -f2 -b8G -e8G -w5 -n20 -dfloat -R0 -G10
${MPIRUN_COMMAND} alltoall_perf -t1 -g1 -f2 -b8G -e8G -w5 -n20 -duint8 -R0 -G10
${MPIRUN_COMMAND} sendrecv_perf -t1 -g1 -f2 -b8G -e8G -w5 -n20 -duint8 -R0 -G10

# Symmetric (MessageSize=2GB)
${MPIRUN_COMMAND} all_reduce_perf -t1 -g1 -f2 -b2G -e2G -w5 -n20 -dfloat -R2 -G10
${MPIRUN_COMMAND} reduce_scatter_perf -t1 -g1 -f2 -b2G -e2G -w5 -n20 -dfloat -R2 -G10
${MPIRUN_COMMAND} env NCCL_SYM_CE_THRESHOLD=17179869184 all_gather_perf -t1 -g1 -f2 -b2G -e2G -w5 -n20 -dfloat -R2 -G10

# CE (MessageSize=8GB)
${MPIRUN_COMMAND} all_gather_perf -t1 -g1 -f2 -b8G -e8G -w5 -n20 -dfloat -R2 -x2
${MPIRUN_COMMAND} alltoall_perf -t1 -g1 -f2 -b8G -e8G -w5 -n20 -duint8 -R2 -x2
```

Notes:

- `-t1` and `-g1` are included to make the one-GPU-per-process mode explicit.
- Adjust `${MPIRUN_COMMAND}` for your system and MPI library. Reference runs used SLURM as:<br>
    `srun -N ${NODES} --ntasks-per-node=${TASKS_PER_NODE} --mpi=pmix`.
- Symmetric kernels have a known performance issue for message sizes greater than 2 GB.
  Performance has improved on the `dev` branch, and additional work is in progress.
- Versions:

  | Platform | CUDA  |  SLURM  |    MPI     |
  | -------- | :---: | :-----: | :--------: |
  | GB300    | 13.3  | 25.11.2 | HPCX v2.24 |
  | B200     | 13.2  | 25.11.2 | HPCX v2.24 |
  | H100     | 12.2  | 24.05.5 | HPCX v2.23 |
<br>
