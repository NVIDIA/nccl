# Using NCCL



Using NCCL is similar to using any other library in your code. For example:

1.  Install the NCCL library onto your system.

    For more information, see {ref}`Downloading NCCL <downloadnccl>`.

2.  Modify your application to link to that library.

3.  Include the header file `nccl.h` in your application.

4.  Create a communicator.

    For more information, see *Creating a Communicator*  in the [NCCL Developer Guide](http://docs.nvidia.com/deeplearning/sdk/nccl-developer-guide/index.html).

5.  Familiarize yourself with the [NCCL API](https://docs.nvidia.com/deeplearning/nccl/user-guide/api.html) documentation to maximize your usage performance.
